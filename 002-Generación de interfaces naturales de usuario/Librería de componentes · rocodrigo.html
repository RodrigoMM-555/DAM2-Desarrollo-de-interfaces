Librería de componentes

Todo lo básico de HTML y CSS con la identidad rocodrigo, listo para copiar. Cada ejemplo tiene su código debajo, y el CSS completo se copia con un solo botón.

Cómo usarla en un proyecto

Copia el CSS una vez en tu estilos.css y usa las clases en tu HTML. Los colores, radios y espacios viven en variables (var(--brand)), así que cambiar la marca es cambiar un bloque. Los modos claro y oscuro funcionan solos según el sistema.

Color

Petróleo como base, rojo vino como contrapunto y amarillo como acento para acciones. Toca un color para copiar su variable.

Tokens que cambian con el tema

Para fondos, textos y bordes usa siempre estos y no los colores fijos: así el modo oscuro funciona sin trabajo extra.

Tipografía

Una sola familia, Ubuntu, con tres pesos: 700 para titulares, 500 para etiquetas y 400 para texto.
